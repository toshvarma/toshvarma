## Projects

### COCO — Android App
An AI-powered social media assistant, built as a university project for a real client of the same name: **COCO**, which helps self-employed professionals and SMEs manage social media without heavy time or training investment.
- Front end built with Dart, Flutter, and Android Studio
- Backend built with Node.js and Express.js
- Integrated the Claude API to power a guided content workflow
- Gathered requirements from and presented the final prototype directly to the client

🔗 https://github.com/toshvarma/coco-app

---

### GermanGenie — Landing Page
A marketing-focused landing page, built as a university project for client **DeutschGenie**, a gamified German-grammar learning platform. "GermanGenie" was our proposed rebrand for international audiences.
- Built with a focus on SEO and performance
- Optimized for GEO via a JSON-LD schema and the Robots Exclusion Protocol
- Clean, responsive layout for accessibility across devices

🔗 https://github.com/toshvarma/germangenie-landingpage
